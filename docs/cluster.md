title: 多机节点
---

在本机登记其它 3m-ui，做探活，以及有限的远程操作（同步节点元数据、合并订阅等）。

## 登记

- 名称  
- Base URL（`http`/`https`）  
- 远程管理员的 JWT  
- 是否启用  

列表里不会回显完整 token。

## 健康检查

对已启用的远程打 `GET /api/v1/health`，结果写入状态和时间。

## 远程操作

视版本可能包括：看远程状态、同步节点镜像到本地、把多个机器的节点拼进同一用户订阅、向远程推节点（常有 dry-run，且远程可默认拒绝推送）。

远程 JWT 权限很大，按机密存。跨公网建议 HTTPS。

本机挂了或 token 过期时，合并订阅里远程那一段会失败或为空，先检查健康状态。
