## 用户字段

| 字段 | 说明 |
|------|------|
| 用户名 | 唯一；删除后可重新创建同名（硬删除） |
| 备注 | 展示名、订阅标题回退等 |
| 分组 / 标签 | 便于筛选与备注；标签可多值 |
| 启用 | 关闭后订阅与认证失败 |
| 流量上限 | 字节；`0` 不限制 |
| 已用流量 | 上/下行累计 |
| 到期时间 | 空表示不限 |
| 流量重置周期（天） | `0` 关闭；每隔 N 天自动清零该用户流量 |
| 到期续期周期（天） | `0` 关闭；到期后自动再延长 N 天 |
| 首次使用起算 | 开启后，到期按「首次连接/拉订阅」起算，而非创建时刻 |
| 首次使用后有效天数 | 与「首次使用起算」配合；首次使用后 N 天内有效 |
| IP 限制 | 并发客户端 IP 上限，`0` 不限 |
| HWID 设备上限 | `0` 不限；兼容 Happ 等客户端在导入订阅时发送的 `x-hwid` 头 |
| 外部订阅链接 | 每行一个 Clash/Mihomo YAML URL，合并进该用户订阅 |
| 在线 | 根据连接情况更新（若已启用探测） |
| sub_token | 订阅路径中的公开令牌 |

## HWID 设备管理

在用户列表可打开 **设备** 弹窗：

- 查看已登记的设备（系统、型号、最后出现时间等）
- 踢出单台设备或清空全部
- 超过 HWID 上限的新设备导入订阅会失败

客户端需在拉订阅时携带 `x-hwid`（及可选设备信息头）。未发送 HWID 的客户端不受设备上限约束（仍受 IP 限制等其它规则约束）。

## 首次使用起算

适用于「先发卡、后使用」的场景：

1. 创建用户时勾选 **首次使用起算**，并填写 **首次使用后有效天数**
2. 用户第一次成功拉取订阅，或产生可统计流量时，写入首次使用时间
3. 到期时间按首次使用 + 天数计算

未开启时，到期仍按创建时填写的绝对时间（或永不过期）。

## 外部订阅合并

在用户编辑中填写 **外部订阅链接**（每行一个 YAML 地址）。生成该用户的 Mihomo/Clash 订阅时，会拉取并合并这些外链中的代理节点（失败的外链会跳过，不影响本地面板节点）。

## 批量操作

支持对多选用户：启用、禁用、重置流量、延期、加流量、删除。

**清理耗尽用户**：删除已到期或超流量用户（保留仅被手动禁用的账号）。

## 流量监控

**流量监控** 页查看汇总、在线连接与按用户统计；用户列表展示已用/上限。

到达上限或过期后，凭据判定为不可用，订阅返回错误，Telegram 可告警（见 [Telegram-Bot](/telegram-bot)）。

## 分享

用户详情/分享弹窗提供：

- Mihomo / Clash 订阅
- V2Ray / Base64
- Sing-box
- HTML 信息页
- 单节点 URI 与二维码
- 一键导出全部订阅链接

复制链接时注意使用 HTTPS 与正确公网 Host（见 [系统设置](/system-settings) 与 [NAT与面板端口](/nat-port)）。
